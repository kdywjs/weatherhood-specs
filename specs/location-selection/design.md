# 지역 선택 설계

요구사항 원본: [requirements.md](requirements.md)

## 화면 구성
메인과 마이페이지의 Noto Sans KR, 흰 카드, 옅은 하늘색 배경, 청색 강조, 모서리 16px, 좌우 여백 20px을 재사용한다. 전체 화면 430×932이며 지역 선택 흐름에서는 하단 탭을 숨기고 닫기/뒤로가기로 복귀한다.

- 지역 선택: 제목 `지역 선택`, 검색 진입 `지역 검색·추가`, 현재 위치 카드, `내 지역` 목록과 편집 버튼. 카드에는 지역명·현재 기온·날씨 아이콘을 표시한다. 현재 위치 카드에는 위치 아이콘을 함께 둔다.
- 선택 표시: 체크는 현재 선택을 의미하며 권한 허용 여부를 나타내지 않는다. 모든 카드의 오른쪽 세로 중앙에 같은 위치로 배치한다.
- 닫기와 편집: 닫기는 X 아이콘, 편집은 텍스트 버튼이다. 각각 최소 44×44 누르기 영역을 확보하고 접근성 이름은 `지역 선택 닫기`, `저장 지역 편집`으로 제공한다.
- 지역 검색: 상단은 뒤로가기와 검색창으로 구성한다. 별도 화면 제목·검색 결과 제목·선택 동작 설명은 표시하지 않는다. 검색창의 빈 상태 문구는 `지역명 검색`이며 입력 중에는 검색어와 지우기 버튼을 표시한다. 뒤로가기와 지우기는 각각 최소 44×44 영역과 접근성 이름을 제공한다.
- 검색 결과: 상위 행정구역을 포함한 전체 지역명을 구분선이 있는 단순 목록으로 표시한다. 행 전체를 눌러 선택하고 별도의 꺾쇠는 두지 않는다. 이미 저장한 결과에만 `저장됨`을 표시한다. 키보드 영역은 시스템 UI 자리 표시이며 앱의 자체 키보드가 아니다.
- 목록 편집: 완료, 고정 현재 위치 항목, 저장 지역 삭제 및 순서 변경. 드래그 외에 위/아래 버튼을 함께 배치한다. 버튼 구성은 접근 가능한 시안 표현이며 구체적인 드래그 구현 방식은 미정이다.
- 위치 안내(요청 전): 현재 위치를 사용하는 목적, 위치 허용, 직접 검색.
- 위치 안내(거부): 설정 열기, 직접 검색. 위치 허용을 앱 설정처럼 가장하지 않는다.

## 이동과 상태
지역 선택 진입 → 검색 결과 선택(저장+전환) 또는 목록 선택 → 진입 화면 복귀. 다른 지역이면 메인 선택을 새 지역 현재 시각·정지로 바꾼다. 같은 지역/닫기이면 선택 시간은 유지한다. 편집 완료는 목록으로 복귀하며 지역을 변경하지 않는다.

현재 위치 모드와 수동 지역은 별도 선택 상태로 표현한다. 현재 위치에서 실제 지역이 변하는 경우의 재확인 정책은 미정이다. 위치 확인 결과가 없거나 실패하면 기존 지역을 유지한다.

## 미정 사항
검색 API와 저장 형식은 미정이다. 오류와 데이터 누락 상세 시안은 후속 작업으로 남기며 요구사항의 예외 규칙은 유지한다.

- 현재 지역 검색 시안: [지역 검색 v2](https://www.figma.com/design/nIUPdpIqFoqtPBCBPwOJ3N?node-id=107-126). 이전 검색 시안은 비교용으로 보존했다.
- 지역 검색 구성 참고: [당근 동네 검색 공개 캡처](https://hongname.tistory.com/57?category=1247492). 2020년 화면이며 최신 앱 확인이나 실제 앱 동작 검증으로 간주하지 않는다.
- 나머지 흐름과 비교 자료: [지역 선택 v1 · 5개 화면](https://www.figma.com/design/nIUPdpIqFoqtPBCBPwOJ3N?node-id=36-974). 이전 시안은 비교용이며 현재 스펙과 충돌하면 본문을 따른다.
- 정적 와이어프레임이다. 실제 검색·권한 요청·삭제·순서 변경은 검증하지 않았다.
- 지역 선택 v2를 내보내 확인한 레이어는 FRAME 16개, TEXT 16개, VECTOR 24개다. 이미지 채우기는 없고 서체는 Noto Sans KR이다. 닫기·편집 영역은 각각 44×44이며 텍스트 잘림과 겹침을 시각적으로 확인했다.
- 전체 흐름 v1은 5개 화면 각 430×932, FRAME 54개, TEXT 64개, VECTOR 46개, 이미지 채우기 없음으로 확인했다.
- 지역 검색 v2는 430×932, FRAME 16개, TEXT 7개, VECTOR 4개, Noto Sans KR, 이미지 채우기 없음으로 확인했다. 별도 제목과 결과 안내가 없고 결과 행 높이는 64px이다. 캔버스에서 전체 지역명·저장됨 표시·구분선과 글자 잘림 여부를 확인했다. `중구`는 입력된 검색어 예시이며 빈 검색창 문구는 본문의 기준을 따른다.
- 확인 자료: 통합 작업 공간의 `design/figma/location-list-v2-preview.png`, `location-selection-v1-preview.png`, `location-selection-v1-validation.json`.
- 지역 검색 확인 자료: 통합 작업 공간의 `design/figma/location-search-v2-preview.png`, `location-search-v2-validation.json`, `location-search-v2.json`.
