# 지역 선택 요구사항

상태: 2026-10-11 사용자 승인 기준. 이 화면의 합의이며 데이터 계약이나 팀 전체 MVP 확정을 의미하지 않는다.

## 목적과 범위
현재 위치 또는 국내 지역을 선택해 날씨를 확인하고, 여러 지역을 기기에 저장해 다시 선택한다. 로그인 없이 사용한다.

## 승인 동작
- 메인과 날씨 정보의 지역명을 눌러 공통 지역 선택 화면을 연다. 열 때 메인 재생을 멈춘다.
- 목록에는 검색 진입, 현재 위치, 저장한 지역, 편집 진입을 둔다. 선택 지역은 체크 표시한다.
- 검색 결과는 같은 이름을 구분하도록 상위 행정구역까지 표시한다.
- 검색 결과를 누르면 저장과 지역 전환을 함께 수행하고 진입 화면으로 복귀한다. 이미 저장한 지역은 중복 추가하지 않는다.
- 다른 지역으로 전환하면 해당 지역의 현재 날짜·시각으로 이동하고 정지한다. 자동 재생하지 않는다. 날씨 정보 화면도 같은 지역을 사용한다.
- 같은 지역 재선택 또는 취소·닫기는 기존 날짜·시각을 보존하고 정지 상태로 복귀한다.
- 저장 지역의 삭제와 순서 변경은 편집 화면에서 제공한다. 현재 위치 항목은 삭제하지 않는다.
- 선택 지역을 저장 목록에서 삭제해도 현재 표시 중인 지역과 날씨는 유지한다.
- 저장 목록과 순서는 로그인 없이 기기에 보관한다.

## 현재 위치와 예외
- 현재 위치가 기본이다. 수동 선택 지역은 사용자가 바꾸기 전까지 고정한다.
- 현재 위치 항목을 선택할 때 권한에 따라 위치를 확인하거나 시스템 권한 요청을 제공한다. 권한 허용만으로 수동 선택 지역을 자동 전환하지 않는다.
- 권한이 이미 거부된 경우 설정 열기와 지역 직접 찾기를 제공한다.
- 위치 확인 실패 시 기존 지역을 유지하고 재시도와 직접 검색을 제공한다.
- 날씨 갱신 실패 시 기존 캐시/실패 안내 규칙을 유지한다. 다른 지역의 캐시를 새 지역 날씨처럼 표시하지 않는다.

## 아직 정하지 않은 것
검색 제공처·지역 식별자·행정구역 해상도, 위치 재확인 시점·정확도·백그라운드 처리, 저장 개수 제한·저장 실패·재설치 정책, 검색 지연·오류 정책은 후속 결정이다. 와이어프레임의 지역과 수치는 가상 예시다.

## 수용 기준
1. 검색 결과 선택으로 저장과 전환이 이루어지고 중복 지역이 생기지 않는다.
2. 다른 지역 전환과 같은 지역 재선택/닫기의 날짜·시각 처리가 구분된다.
3. 위치 권한 없이 국내 지역 검색·선택이 가능하다.
4. 현재 위치 모드와 고정 지역이 구분되며 선택은 색과 체크로 함께 표시한다.
5. 목록 삭제가 현재 날씨를 임의의 다른 지역으로 바꾸지 않는다.
