# 지역 선택 작업 분해

관련 작업: [와이어프레임 설계 및 수정 #2](https://github.com/kdywjs/weatherhood-specs/issues/2). 담당자·일정·진행 상태는 연결된 GitHub Project에서 관리한다.

1. 승인된 지역 저장·전환·편집·권한 동작을 요구사항으로 기록한다.
2. 기존 원본 Figma 파일에 지역 선택, 검색 결과, 목록 편집, 위치 요청 전/거부 안내의 편집 가능한 프레임을 추가한다.
3. 서체·화면 크기·잘림·겹침·체크 표시·텍스트와 버튼으로 가능한 순서 변경을 확인한다.
4. 위치 재확인 정책과 저장·실패 API 계약을 구현 전에 합의한다. 서버 검색·지역 매핑 작업은 [서버 작업](server-tasks.md)을 참조한다.
5. 구현 시 중복 저장 방지, 지역 변경 시 현재 시각 정지, 같은 지역/닫기의 상태 보존, 삭제 시 현재 날씨 유지, 권한 거부 시 수동 검색을 검증한다.

정적 Figma 확인과 실제 구현 검증을 구분한다.
