# 법률 문서 읽기 설계

## 화면 구성
430×932 화면 두 개를 가로 비교 보드로 배치한다. 제목·본문·시행일 값만 바뀌는 공통 구조다. 마이·지역 목록의 Noto Sans KR, 옅은 하늘색 배경과 본문색을 재사용한다.

- 상단: 44×44 뒤로가기 영역과 문서 제목. 접근성 이름은 `마이로 돌아가기`다.
- 본문: 좌우 20px, 폭 390px의 읽기 영역. 시행일, 절 제목, 문단 순서다. 상단은 유지하고 본문을 세로 스크롤하는 구조다.
- 동의·확인 버튼과 하단 탭은 두지 않는다.

## 문구와 상태
시행일은 `시행일: [실제 문서의 시행일 · 미정]`으로 표시한다. 본문에 `문서 구조 검토용 자리 표시`와 `실제 법률 본문이 아닙니다.`를 명시한다. `[절 N 제목 · 실제 문서 제공 후 대체]`와 `[문단 자리 표시]`는 배치 검토용이며 절 수나 법률 내용을 확정하지 않는다.

실제 문서 제공 후 해당 내용으로 대체한다. 제공 방식·실제 로딩 정책·오류·빈 문서 상태는 미정이다. JSON은 정적 레이어 배치이며 스크롤·메뉴 이동·뒤로가기가 연결된 프로토타입이 아니다.

## 이동과 제약
마이에서 선택한 문서 종류에 맞춰 제목·본문·시행일을 표시하고 뒤로가면 마이로 복귀한다. 날씨 선택 지역·날짜·시각·재생 상태를 변경하지 않는다. 앱·서버 책임과 데이터 계약은 제공 정책 결정 후 정한다.

마이의 이용약관·개인정보 처리방침은 이 공통 읽기 화면으로 연결한다. 진입 기준은 [마이 요구사항](../my-page/requirements.md)을 따른다.

## 참고 및 검증
- JSON: 통합 작업 공간 `design/figma/legal-documents-v1.json`.
- 원본: `design/figma/my-page-v1.json`, `design/figma/location-list-v2.json`.
- JSON 파싱, 430×932 프레임 두 개, 동일 레이어 크기·좌표, Noto Sans KR, 자리 표시, 44×44 뒤로가기와 동의·확인 버튼 부재를 구조 검증했다.
- 시안: [마이와 문서 읽기 화면](https://www.figma.com/design/nIUPdpIqFoqtPBCBPwOJ3N?node-id=144-250). sub03 JSON을 root가 기존 Figma 파일에 JSON Import / Export로 가져왔다.
- 마이 포함 비교 보드의 실제 레이어는 FRAME 34개, RECTANGLE 3개, TEXT 39개, VECTOR 34개다. Noto Sans KR과 이미지 채우기 없음을 확인했고 제목·문단·자리 표시·뒤로가기의 글자 잘림과 겹침을 캔버스에서 확인했다.
- 증적: 통합 작업 공간 `design/figma/app-info-v2-import.json`, `app-info-v2-validation.json`, `app-info-v2-preview.png`.
- 실제 스크롤·뒤로가기·메뉴 이동·상태 보존은 검증하지 않았다. 실제 본문·시행일·제공 정책은 미정이다.
