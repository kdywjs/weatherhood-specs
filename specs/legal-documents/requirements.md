# 법률 문서 읽기 요구사항

## 목적과 범위
마이의 이용약관·개인정보 처리방침 메뉴에서 문서를 읽는 공통 화면이다. 문서별로 제목·본문·해당 문서의 시행일만 바뀐다. 이번 범위는 스펙과 정적 와이어프레임까지다.

## 현재 요구사항
- 상단에 뒤로가기와 문서 제목을 표시한다.
- 본문은 세로 스크롤로 읽고, 준비된 실제 문서에 있는 시행일을 표시한다.
- 읽기 화면이므로 동의·확인 버튼을 두지 않는다.
- 뒤로가면 마이로 복귀한다. 날씨 선택 지역·날짜·시각·재생 상태를 변경하지 않는다.
- 실제 문서의 절·문단 순서를 보존하며 두 문서는 같은 구조를 사용한다.

## 미정 사항과 예외
실제 본문과 시행일, 문서 제공 방식과 실제 로딩 정책은 미정이다. 로딩·실패·빈 문서 상태와 재시도는 제공 정책과 함께 정한다. 시행일 없는 문서의 표시 정책도 미정이다. 법률 문구·연락처·날짜를 임의 생성하지 않는다. 시안의 본문은 절·문단 구조 검토용 자리 표시로 명확히 구분한다.

## 범위 밖
앱·서버 구현, 실제 문서 작성, 동의 수집, 기능이 연결된 프로토타입은 포함하지 않는다.

## 수용 기준
1. 각 메뉴의 제목·본문을 같은 읽기 구조로 표시한다.
2. 긴 문서의 끝까지 세로 스크롤로 읽을 수 있다.
3. 실제 문서에 있는 시행일만 표시한다.
4. 뒤로가면 마이에 복귀하고 날씨 선택 상태를 보존한다.
5. 동의·확인 버튼이 없고 자리 표시가 실제 본문과 구별된다.
