# 문의하기 작업 분해

## 작업과 의존 관계
1. 실제 수신 이메일 주소를 결정한다. 임의 주소를 사용하지 않는다.
2. 제목 `웨더후드 문의`, 사용자 본문 작성·직접 전송, 열기 실패 시 주소·복사 버튼 제안을 검토하고 확정 여부를 결정한다.
3. 주소 미정 시 동작, 연결 방식, 실패 판단·안내 형식과 문구, 복사 결과 안내를 결정한다.
4. 합의 결과를 문의 스펙과 마이페이지의 문의 관련 항목에 반영한다.
5. 주소와 연결·예외 정책 확정 및 구현 요청 후 앱의 기존 문의하기 행에 이메일 연결과 합의된 실패 처리를 구현한다. 지원 서버·앱 내 문의 폼·접수 완료 화면은 추가하지 않는다.
6. 대상 플랫폼 실제 기기에서 이메일 작성 연결, 앱 없음·연결 오류, 취소·복귀와 합의된 복사 동작을 검증한다. 작성 UI 열기를 전송·접수 완료로 처리하지 않는지 확인한다.

주소 미정으로 연결 구현과 실제 실패 안내를 아직 확정할 수 없다. 이번 범위는 문서 준비이며 앱 구현과 실제 이메일 전송은 포함하지 않는다. 담당·일정·진행 상태는 이 문서에 중복 관리하지 않는다.
