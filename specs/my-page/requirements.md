# 마이페이지 요구사항

## 목적과 화면
로그인 없이 캐릭터와 앱 설정을 관리하는 화면이다. 하단 `마이` 탭에서 진입한다.
이 문서는 마이페이지의 기준이며 팀 전체 MVP와 꾸미기 세부 범위 확정을 뜻하지 않는다.

| 영역 | 요구사항 |
| --- | --- |
| 상단 | 현재 캐릭터 미리보기. 닉네임·프로필 사진·로그인 버튼은 표시하지 않는다. |
| 캐릭터 꾸미기 | 꾸미기 화면 진입 메뉴를 둔다. 옷 종류·꾸미기 항목·자동 날씨 표현과의 관계는 별도 스펙으로 정한다. |
| 설정 | 온도 단위 °C / °F만 제공한다. 기본값은 °C다. |
| 앱 정보 | 앱 버전, 문의하기, 이용약관, 개인정보 처리방침. |

## 동작과 저장
- 로그인 없이 첫 사용부터 이용하며 온도 단위는 기기에 저장한다.
- 온도 단위를 바꾸면 메인과 날씨 정보의 모든 온도 표시에도 동일하게 적용한다. 시간·지역·선택 날짜·날씨 데이터의 의미는 유지한다.
- 마이페이지로 이동하면 메인 재생을 멈추고 선택 지역·날짜·시각은 보존한다.
- 메인으로 돌아오면 기존 선택 지역·날짜·시각에 정지 상태로 머문다.
- 앱 버전은 읽기 전용 정보다. 문의 전달 방식·연락처와 약관 본문·표시 방식은 출시 준비 시 정한다. 시안에서는 실제 연락처·약관 내용·버전을 임의로 만들지 않는다.

## 범위 밖과 미정
움직임 줄이기 메뉴는 사용자 요청에 따라 제외한다. 상황 개인화 입력, 로그인, 푸시·위젯은 이번 화면에 넣지 않는다. 일반적인 접근성 원칙을 삭제하는 결정은 아니다. 꾸미기 하위 화면, 데이터 저장 세부·재설치 시 유지 정책, 문의·약관 하위 화면과 설정 저장 실패 동작은 미정이다. 정적 와이어프레임 제작은 이 항목으로 막지 않는다.

## 수용 기준
1. 캐릭터 미리보기, 꾸미기 진입, 온도 단위, 앱 정보가 한 화면에서 확인된다.
2. 움직임 줄이기·개인화 입력·로그인 항목이 없다.
3. °C와 °F는 텍스트 선택지이며 선택 상태를 색뿐 아니라 선택 표시로 구분한다.
4. 앱 구현에서는 단위 선택이 화면 간 공유되고 앱 재실행 후 유지된다.
5. 탭 전환으로 메인의 선택 지역·날짜·시각을 잃거나 자동 재생하지 않는다.
6. Figma는 편집 가능한 텍스트·벡터·프레임으로 구성한다. 구현 완료나 연결된 프로토타입으로 표현하지 않는다.
