# 마이페이지 설계

요구사항 원본: [requirements.md](requirements.md)

## 화면 구성
- 메인 v3의 Noto Sans KR·흰색·옅은 하늘색·청색 강조·선형 아이콘을 재사용한다.
- 430×932, 좌우 20px, 메뉴 그룹 모서리 16px, 행 높이 56px 이상.
- 상단 제목 `마이`, 하늘색 캐릭터 미리보기와 `캐릭터 꾸미기` 진입. 기존 캐릭터 벡터를 재사용하고 임의의 개인화나 새 캐릭터 자산을 만들지 않는다.
- 설정은 하나의 온도 단위 행과 °C / °F 선택 영역. °C에 선택 표시를 둔다.
- 앱 정보는 버전·문의·약관·개인정보 처리방침을 목록으로 표시한다. 버전은 `출시 전`이라는 시안 표시를 사용하고 실제 버전 번호로 간주하지 않는다.
- 하단 날씨 / 날씨 정보 / 마이, 마이 활성 상태. 구현 시 탭 고정, 필요하면 본문 스크롤.

## 상태와 저장
앱 설정은 로컬 상태와 로컬 저장소로 관리한다. 저장 형식과 서버 계약은 미정이다. 화면 간 단위 공유와 탭 전환 동작은 요구사항을 따른다.

## 참고 및 검증
- 시안: [마이 v1 와이어프레임](https://www.figma.com/design/nIUPdpIqFoqtPBCBPwOJ3N?node-id=28-899). 기존 메인과 날씨 정보 시안은 보존했다.
- 정적 와이어프레임이다. 실제 단위 변경·꾸미기 이동·외부 문의·약관 연결은 검증하지 않았다.
- 문자·아이콘·캐릭터가 편집 가능한 레이어임을 확인했고, 430×932 화면의 잘림과 항목 겹침을 시각적으로 확인했다.
- 확인 자료: 통합 작업 공간의 `design/figma/my-page-v1-preview.png`.
