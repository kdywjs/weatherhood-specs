# 마이페이지 설계

요구사항 원본: [requirements.md](requirements.md)

## 화면 구성
- 메인 v3의 Noto Sans KR·흰색·옅은 하늘색·청색 강조·선형 아이콘을 재사용한다.
- 430×932, 좌우 20px, 메뉴 그룹 모서리 16px, 행 높이 56px 이상.
- 상단 제목 `마이`, 하늘색 캐릭터 미리보기와 `캐릭터 선택` 진입. 기존 캐릭터 벡터를 재사용하고 임의의 개인화나 새 캐릭터 자산을 만들지 않는다.
- 설정은 하나의 온도 단위 행과 °C / °F 선택 영역. °C에 선택 표시를 둔다.
- 앱 정보는 버전·문의·약관·개인정보 처리방침을 목록으로 표시한다. 버전은 `출시 전`이라는 시안 표시를 사용하고 실제 버전 번호로 간주하지 않는다.
- 문의하기 행은 OS·외부 이메일 작성 연결의 진입점이다. 이용약관·개인정보 처리방침 행은 제목과 본문이 바뀌는 공통 문서 읽기 화면으로 이동한다. 연결과 예외는 각 기능 스펙을 따른다.
- 하단 날씨 / 날씨 정보 / 마이, 마이 활성 상태. 구현 시 탭 고정, 필요하면 본문 스크롤.

## 상태와 저장
앱 진입 시 로그인하며 지역·캐릭터 설정은 사용자별 서버 DB에 저장한다. 온도 단위는 로컬 저장을 유지하며 서버 동기화 여부는 미정이다. 저장 형식과 서버 계약, 기기 간 동기화·실패 처리는 후속 설계한다. 화면 간 단위 공유와 탭 전환 동작은 요구사항을 따른다.
