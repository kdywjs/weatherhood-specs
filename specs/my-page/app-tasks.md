# 마이페이지 작업 분해

진행상황 기준: [와이어프레임 설계 및 수정 Issue #2](https://github.com/kdywjs/weatherhood-specs/issues/2), Weatherhood GitHub Project. 이 문서는 구현 작업과 의존 관계를 설명하며 일정·담당·상태를 중복 관리하지 않는다.

1. 승인 스펙을 바탕으로 기존 파일에 마이페이지 정적 시안을 제작한다.
2. 캐릭터 미리보기·메뉴·온도 선택 표시·하단 탭의 배치와 편집 가능 여부를 확인한다.
3. 캐릭터 종류·자산과 선택 적용·저장 동작을 캐릭터 선택 스펙에서 결정한다.
4. 온도 단위의 로컬 저장·화면 간 공유와 사용자별 캐릭터 설정의 서버 조회를 구현한다. API와 동기화·실패 정책은 구현 전에 합의한다.
5. 문의 수신 주소·이메일 연결 및 예외 정책, 문서 본문·시행일·제공 정책, 앱 버전 정보를 준비하고 각 기능 스펙에 따라 연결한다.
6. 단위 변경 및 재실행 유지, 탭 전환 후 메인 시각 보존·정지 상태를 검증한다.

이번 요청은 승인 스펙 기록과 정적 와이어프레임 제작까지다.
