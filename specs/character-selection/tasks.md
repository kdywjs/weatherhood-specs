# 캐릭터 선택 작업 분해

## 준비와 의존 관계
1. MVP 종류 선택과 미정 사항을 구분하고 기존 JSON을 재사용한다.
2. JSON의 프레임·텍스트·SVG 구조, 서체 지정, 좌표 범위와 원본 벡터 재사용을 확인한다.
3. root가 기존 Figma 파일에 JSON Import / Export 플러그인으로 새 비교 시안을 추가한다. 기존 프레임을 보존한다.
4. root가 실제 레이어·서체·스크린샷과 잘림·겹침을 확인하고 실제 노드 링크를 설계 문서 마지막에 연결한다.
5. 실제 캐릭터 목록·자산, 적용·뒤로가기, 저장·실패 동작을 합의한 뒤 앱 구현 범위를 정한다.
6. 합의 후 선택·저장·재실행·실패 동작과 날씨 자동 의상 표현의 관계를 구현·검증한다.

마이페이지 진입 메뉴 정리는 별도 담당 범위다. 문의하기 작업과 겹치지 않는다. 이 문서는 작업 분해만 다루며 담당·일정·진행 상태는 중복 관리하지 않는다.

- 관련 작업: 와이어프레임 설계 및 수정 Issue #2. 이번 작업에서 Issue·Project·커밋·푸시를 변경하지 않는다.
- sub01 전달 범위는 JSON·스펙 문서 준비와 JSON 구조 검증까지다. 가져오기·시각 검증은 root가 수행한다.
