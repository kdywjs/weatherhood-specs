# 캐릭터 선택 요구사항

## 목적과 범위
사용자가 자신의 캐릭터 종류를 선택하는 기능이다. MVP는 캐릭터 종류 선택만 제공한다. 옷은 날씨에 따라 자동으로 바뀌며, 사용자가 옷을 꾸미는 기능은 후속 범위다.

## 현재 요구사항
- 종류를 비교하고 선택할 수 있는 화면을 제공한다.
- 현재 제품의 색, 서체와 기존 캐릭터 벡터를 재사용한다.
- 정적 시안은 편집 가능한 텍스트·벡터·프레임으로 준비한다.
- 실제 캐릭터 종류·개수·외형이 확정되기 전에는 예시 슬롯을 확정된 목록이나 완성된 자산으로 표시하지 않는다.

## 범위 밖과 미정
옷 꾸미기는 MVP에서 제외한다. 눈·몸체 개별 편집 여부는 미정이며, 종류 선택으로 이를 확정하거나 배제한 것으로 해석하지 않는다.

실제 종류·개수·외형, 최초 기본 선택, 적용·뒤로가기 동작, 선택 저장 방식과 재실행·재설치 시 유지 정책, 저장 실패와 자산 로딩 실패 동작은 미정이다. 큰 미리보기·썸네일 선택과 적용·뒤로가기 흐름은 시안 제안이다.

## 수용 기준
1. 종류 선택이 화면의 중심이며 옷 편집 조작을 제공하지 않는다.
2. 옷 자동 변경과 후속 옷 꾸미기 범위를 구분한다.
3. 눈·몸체 개별 편집과 실제 캐릭터 목록을 미정으로 유지한다.
4. 선택 표시는 색뿐 아니라 체크와 텍스트로 구분한다.
5. 정적 시안과 앱 구현·저장 동작 검증을 구분한다.
