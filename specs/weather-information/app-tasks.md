# 날씨 정보 작업

관련 작업: [와이어프레임 설계 및 수정 #2](https://github.com/kdywjs/weatherhood-specs/issues/2). 담당자·일정·진행 상태는 연결된 GitHub Project에서 관리한다.

1. 요구사항과 설계를 바탕으로 전체 콘텐츠 및 첫 화면 시안을 구성한다.
2. 편집 가능한 레이어·서체·표시 상태를 확인하고 증적은 설계 문서 끝에 연결한다.
3. 하단 탭 없는 날씨 정보 진입 조작과 날짜별 요약만 있는 날짜의 메인 진입 처리를 결정한다.
4. [지역별 날씨 데이터 작업](../weather-data/server-tasks.md)에 따라 기상청 공급 범위·10일 가능 여부를 확인한다. 평균 집계와 부가 지표의 공급 경로는 별도로 정한다.
5. [날씨 API 계약](../../contracts/weather-api.md)을 실제 공급 응답 및 앱 모델과 맞춘다.
6. 앱을 구현하고 시간/날짜 선택·화면 복귀·스크롤·오늘 지난 시간 탐색과 결측 표시를 검증한다.

정적 와이어프레임 검증과 실제 앱 동작 검증은 구분한다. 검증 증적은 [design.md](design.md)의 마지막 항목에서 참조한다.
