# 날씨 정보 앱 작업

원본은 [요구사항](requirements.md)과 [설계](design.md)다. 기존 와이어프레임 검토는 [Issue #2](https://github.com/kdywjs/weatherhood-specs/issues/2)를 참조한다.

1. 고정 배경 위 주간 목록과 현재 날씨 전환, 날짜·주요 날씨·최저/최고·범위 막대를 구성한다.
2. 좌우 스와이프, 슬라이더 연속 드래그·탭·접근성 조절, 세로 목록 스크롤의 충돌을 검증한다.
3. 읽기 전용 날짜 행, 전환 시 재생 정지·선택 시각 보존을 검증한다.
4. 실제 주간 데이터 공급 범위와 계약을 확인한 뒤 연동한다. 7일 샘플·10일 이전 시안을 운영 보장으로 처리하지 않는다.
5. 후속 현재 요약·시간별·지표 카드의 데이터·누락·진입 동작을 별도 구현·검증한다.
6. [날씨 표현](../weather-presentation/app-tasks.md)의 효과·캐릭터·태양 시각 연동과 분리해 검증한다.

실행 방법과 미검증 항목은 앱 README를 참조한다. 담당·일정·진행 상태는 GitHub Project에서 관리한다.
