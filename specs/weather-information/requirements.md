# 날씨 정보 요구사항

## 목적과 범위
캐릭터 중심 메인은 유지한다. 기존 주간 탭을 `날씨 정보`로 확장하여 현재 날씨, 시간별 예보, 날짜별 예보와 지표를 세로 스크롤로 확인한다. 이 문서는 날씨 정보 화면의 기준이며 팀 전체 MVP 및 데이터 계약 확정을 의미하지 않는다.

## 화면과 동작
- 상단: 메인과 동일한 선택 지역, 현재 기온·날씨 상태·오늘 최고/최저.
- 시간별: 지금부터 24시간의 시간·날씨 아이콘·기온을 한 줄로 표시하고 좌우 스크롤한다. 자정을 넘는 위치에 다음 날짜를 표시한다. 예보 간격은 데이터 해상도 확정 후 결정한다.
- 날짜별: 오늘을 포함한 10일을 잠정 디자인 기준으로 한다. 날짜·날씨 아이콘·최저/최고·기온 범위 막대를 표시한다. 막대는 목록 전체에 동일한 온도 눈금을 적용한다.
- 카드 순서: 강수량 → 바람 → 대기질 → 체감온도 → 습도 → 자외선 → 일출/일몰 → 평균. 카드는 추가 상세 화면을 열지 않는다.
- 시간 항목을 누르면 선택 지역·해당 날짜·시각의 메인으로 이동해 재생한다.
- 날짜 행을 누르면 오늘은 현재 시각, 이후 날짜는 00시의 메인으로 이동해 재생한다.
- 단순 탭 전환은 메인의 재생을 멈춘다. 선택 지역·날짜·시각은 보존하며, 메인 복귀 시 정지 상태로 유지한다.
- 선택 이동 후 메인 장면·기온·캐릭터·지표는 동일 시각을 가리킨다. 하루 끝 정지와 드래그 시 정지 규칙을 유지한다.
- 하단 탭은 날씨 / 날씨 정보 / 마이. 이 합의로 마이 하위 기능을 확정하지 않는다.

## 카드 의미
강수량은 오늘 누적/예상 총량과 기준 기간을 함께 표시한다. 바람·대기질·체감온도·습도는 현재 기준, 자외선은 오늘 최대, 일출/일몰은 오늘 기준으로 한다. 평균은 오늘 기온과 과거 같은 시기 평균의 비교이며 단순 하루 평균값이 아니다. 공급 데이터와 집계 정의는 계약 단계에서 확정한다.

## 보류
정보 누락·로딩·오류 디자인은 이번 화면 작업에서 보류한다. 기존 정보 없음/0/현상 없음 구분과 오류 원칙을 삭제하지 않는다. 10일 제공 가능 여부, 공급처·비용·시간 해상도, 평균 비교 기준, 재생 속도, 캐시 정책은 미정이다. 데이터 없는 기간을 임의로 만들지 않는다.

## 수용 기준
1. 상단 요약 → 시간별 → 날짜별 → 카드 순서로 탐색할 수 있다.
2. 시간별 가로 탐색은 지금부터 다음 날까지 연결되고 날짜 경계가 보인다.
3. 시간·날짜 선택 이동과 단순 탭 복귀의 재생 상태가 구분된다.
4. 기온 범위 막대와 수치가 함께 있어 색 없이도 날짜별 기온을 비교할 수 있다.
5. 하단 탭은 앱에서 고정되며 콘텐츠 스크롤에 가려지지 않는다.
6. Figma 예시 수치는 가상 데이터로 구분되고 실제 구현 완료로 표현하지 않는다.
