# 날씨 정보 요구사항

## 목적과 범위

메인의 배경과 상단 지역 위치를 유지하며 주간 날씨 컴포넌트로 전환한다. 별도 하단 탭·팝업·바텀시트·딤드·닫기 X는 사용하지 않는다. 날씨 기반 배경·캐릭터 기준은 [날씨 표현](../weather-presentation/requirements.md)을 따른다.

## 현재 화면과 동작

- 메인 지역은 가운데 텍스트로 표시하며 날짜 선택 메뉴는 제거한다.
- 메인에서 왼쪽 스와이프로 주간 날씨가 오른쪽에서 들어오고, 반대 방향으로 메인에 돌아온다. 배경은 이동하지 않는다.
- 하단의 작은 `현재 날씨 / 주간 날씨` 텍스트 슬라이더로도 전환한다. 드래그 위치에 따라 주간 컴포넌트가 연속 이동하고 놓으면 끝 위치에 정착한다. 탭·접근성 조절도 제공한다.
- 주간 목록은 상단 지역 아래 배치하며 현재 기온·시간 눈금 등 메인 본문은 주간 전환에 따라 숨긴다. 화면이 길면 목록을 세로 스크롤한다.
- 각 날짜는 날짜·요일, 주요 날씨 아이콘과 문구, 최저·최고, 목록 공통 눈금의 기온 범위 막대를 표시한다.
- 날짜 행은 읽기 전용이다. 탭 시 펼침·캐릭터 상세 화면 이동·자동 재생은 제공하지 않는다.
- 화면 전환과 슬라이더 조작은 재생을 멈추고 메인 선택 시각을 보존한다. 복귀 후에도 정지 상태다. 오늘 지난 시간 탐색·하루 끝 정지·시간 드래그 정지 원칙을 유지한다.
- 지역·날짜별 실제 데이터 제공은 [날씨 데이터](../weather-data/requirements.md)와 관련 계약을 따른다. 로컬 7일 샘플을 운영 제공 일수로 보장하지 않는다.

## 후속 정보 확장

현재 요약(실제 현재 기온·날씨·최고/최저), 지금부터 24시간의 가로 예보와 자정 날짜 경계, 지표 카드는 후속 화면 범위로 보존한다. 기존 10일 기준은 잠정 디자인이며 실제 공급 범위 확인이 필요하다. 시간 항목 선택 이동·자동 재생은 해당 정보 화면 구현 시 검증하며 현재 읽기 전용 주간 목록에 적용하지 않는다.

지표 카드 순서는 강수량 → 바람 → 대기질 → 체감온도 → 습도 → 자외선 → 일출/일몰 → 평균이다. 카드 추가 상세 화면은 열지 않는다. 기존 항목의 존재가 현재 API 제공·앱 구현 완료를 뜻하지 않는다.

## 카드 의미
강수량은 오늘 누적/예상 총량과 기준 기간을 함께 표시한다. 바람·대기질·체감온도·습도는 현재 기준, 자외선은 오늘 최대, 일출/일몰은 오늘 기준으로 한다. 평균은 오늘 기온과 과거 같은 시기 평균의 비교이며 단순 하루 평균값이 아니다. 공급 데이터와 집계 정의는 계약 단계에서 확정한다.

## 예외와 미정

정보 없음·유효한 0·현상 없음은 구분한다. 로딩·실패 상세 UI, 실제 주간 API·제공 일수, 시간 해상도와 후속 카드 데이터 공급은 미정이다. 데이터 없는 날짜·시간을 생성하지 않는다. 최신 요약과 선택 시간 자료를 혼용하지 않는다.

## 수용 기준

1. 배경이 고정된 상태에서 주간 컴포넌트만 좌우 이동한다.
2. 하단 슬라이더의 연속 드래그·탭·접근성 조절로 전환할 수 있다.
3. 주간 목록의 날짜·주요 날씨·수치·범위 막대를 확인하고 세로 스크롤할 수 있다.
4. 날짜를 눌러도 상세 화면·캐릭터로 이동하거나 재생하지 않는다.
5. 전환 후 시각이 보존되고 재생은 정지한다.
6. 후속 정보 화면과 가상 데이터는 실제 연동 완료로 표현하지 않는다.

## 참고 및 검증

- 승인 근거: 사용자가 별도 탭·딤드·X·날짜 상세 이동 제거, 고정 배경, 상단 주간 목록, 텍스트 슬라이더와 연속 드래그를 요청했다.
- 이전 전체 정보 화면은 후속 범위·비교 시안이다. 현재 설계와 검증 한계는 [design.md](design.md)를 참조한다.
