# 날씨 정보 요구사항

## 목적과 범위
캐릭터 중심 메인은 유지하며 `날씨 정보`에서 현재 날씨, 시간별 예보, 날짜별 예보와 지표를 세로 스크롤로 확인한다. 하단 탭은 제거하고 날씨 정보 기능은 별도 경로로 유지한다. 구체적인 진입 조작은 미정이다. 데이터 공급과 계약은 [지역별 날씨 데이터](../weather-data/requirements.md)를 따른다.

## 화면과 동작
- 상단: 메인과 동일한 선택 지역, 현재 기온·날씨 상태·오늘 최고/최저.
- 시간별: 지금부터 24시간의 시간·날씨 아이콘·기온을 한 줄로 표시하고 좌우 스크롤한다. 자정을 넘는 위치에 다음 날짜를 표시한다. 예보 간격은 데이터 해상도 확정 후 결정한다.
- 날짜별: 오늘을 포함한 10일을 잠정 디자인 기준으로 한다. 날짜·날씨 아이콘·최저/최고·기온 범위 막대를 표시한다. 막대는 목록 전체에 동일한 온도 눈금을 적용한다.
- 카드 순서: 강수량 → 바람 → 대기질 → 체감온도 → 습도 → 자외선 → 일출/일몰 → 평균. 카드는 추가 상세 화면을 열지 않는다.
- 시간 항목을 누르면 선택 지역·해당 날짜·시각의 메인으로 이동해 재생한다.
- 시간별 자료가 있는 날짜 행을 누르면 오늘은 현재 시각, 이후 날짜는 00시의 메인으로 이동해 재생한다. 00시 자료가 없거나 날짜별 요약만 있는 날의 진입 동작은 미정이며 시간별 값을 만들어 채우지 않는다.
- 단순 화면 전환은 메인의 재생을 멈춘다. 선택 지역·날짜·시각은 보존하며, 메인 복귀 시 정지 상태로 유지한다.
- 선택 이동 후 메인 장면·기온·캐릭터·지표는 동일 시각을 가리킨다. 하루 끝 정지와 드래그 시 정지 규칙을 유지한다.
- 오늘의 지나간 시간도 메인에서 탐색할 수 있다. 날씨 정보 상단 요약은 실제 현재 시각 기준을 유지한다.

## 카드 의미
강수량은 오늘 누적/예상 총량과 기준 기간을 함께 표시한다. 바람·대기질·체감온도·습도는 현재 기준, 자외선은 오늘 최대, 일출/일몰은 오늘 기준으로 한다. 평균은 오늘 기온과 과거 같은 시기 평균의 비교이며 단순 하루 평균값이 아니다. 공급 데이터와 집계 정의는 계약 단계에서 확정한다.

## 보류
정보 누락·로딩·오류의 상세 화면은 보류하며 데이터 상태는 날씨 API 계약을 따른다. 정보 없음/0/현상 없음은 구분한다. 공급처는 기상청이며 실제 10일 제공 가능 여부·시간 해상도, 평균 비교 기준, 재생 속도와 진입 방식은 미정이다. 수집·보존 정책은 지역별 날씨 데이터 스펙을 따른다. 데이터 없는 기간을 임의로 만들지 않는다.

## 수용 기준
1. 상단 요약 → 시간별 → 날짜별 → 카드 순서로 탐색할 수 있다.
2. 시간별 가로 탐색은 지금부터 다음 날까지 연결되고 날짜 경계가 보인다.
3. 시간·날짜 선택 이동과 단순 화면 복귀의 재생 상태가 구분된다.
4. 기온 범위 막대와 수치가 함께 있어 색 없이도 날짜별 기온을 비교할 수 있다.
5. 하단 탭 없이 날씨 정보에 진입할 수 있다. 구체적인 진입 조작은 확정 후 앱에서 검증한다.
6. Figma 예시 수치는 가상 데이터로 구분되고 실제 구현 완료로 표현하지 않는다.
