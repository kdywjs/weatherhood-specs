# 날씨 정보 설계

요구사항 원본: [requirements.md](requirements.md).

## 현재 앱 구성

- 고정 배경과 상단 헤더·가운데 지역 텍스트 위에 SwiftUI 주간 목록을 배치한다. 하단 고정 탭은 없다.
- 주간 이동 진행률을 하단 슬라이더와 공유해 목록의 수평 위치와 메인 본문의 투명도를 갱신한다. 직접 드래그는 손가락을 따르고 종료 시 정착한다.
- 닫힌 목록은 터치와 접근성 탐색 대상에서 제외한다. 열린 목록의 세로 스크롤과 가로 닫기 제스처를 구별한다.
- 목록은 캐릭터 상세 진입 없는 읽기 전용이며 날짜·주요 날씨·최저/최고·공통 범위 막대를 제공한다.
- 현재 앱은 LINE Seed KR와 반투명 흰 목록을 사용한다. 큰 글자와 짧은 화면은 스크롤로 탐색한다.
- 실제 데이터·태양 시각·의상 연동은 [날씨 표현 설계](../weather-presentation/design.md)와 [오늘 날씨 계약](../../contracts/today-weather-api.md)을 참조한다. 화면 전환으로 날짜·선택 시각을 변경하지 않는다.

## 후속 전체 정보 화면

상단 현재 요약·시간별·확장 날짜별 목록·지표 카드는 후속 범위다. 아래 v1 시안의 430px, Noto Sans KR, 2열 카드, 하단 탭은 과거 검토 자료이며 현재 앱의 내비게이션·서체를 대체하지 않는다. 오늘 날씨 계약에 추가된 일출·일몰과 대기질은 실제 앱 연결이 별도 필요하다. 자외선·평년 비교 등 미제공 지표는 완료로 표시하지 않는다.

## 참고 및 검증
- 시안: [전체 콘텐츠 v1](https://www.figma.com/design/nIUPdpIqFoqtPBCBPwOJ3N?node-id=24-126), [첫 화면 v1](https://www.figma.com/design/nIUPdpIqFoqtPBCBPwOJ3N?node-id=24-512).
- 디자인 기준: [메인 v3](https://www.figma.com/design/nIUPdpIqFoqtPBCBPwOJ3N?node-id=19-126), [Apple 날씨 구성 참고](https://support.apple.com/guide/iphone/check-the-weather-iph1ac0b35f/26/ios/26).
- 시안의 서울 중구, 2026-10-10 15시, 12도·비/바람, 최저 10도·최고 18도는 가상 예시다. 나머지 시간별·10일·카드 수치도 레이아웃 검토용이다.
- 기존 파일에 두 프레임을 추가하고 기존 시안은 보존했다. 텍스트·프레임·SVG 벡터로 구성했으며 전체 UI를 이미지로 가져오지 않았다. 서체는 Noto Sans KR이다.
- 브라우저 캔버스에서 요약·시간별·10일 목록·8개 카드·하단 탭 표시를 확인했다. 전체 콘텐츠와 첫 화면은 정적 시안이며 실제 스크롤·재생·이동은 검증하지 않았다.
- 기존 시안의 하단 탭은 비교 자료이며 현재의 하단 탭 제거 기준과 다르다. 현재 진입 방식은 본문의 스와이프·슬라이더 기준을 따른다.
- 확인 자료: 통합 작업 공간의 `design/figma/weather-information-v1-preview.png`.

- 오늘 로컬 앱의 주간 목록·슬라이더·SpriteKit은 가상 데이터 기반이다. 빌드와 제한된 실행 확인을 전체 터치 조합·실기기·실제 API 검증으로 해석하지 않는다. 실행 검증은 앱 README를 참조한다.
