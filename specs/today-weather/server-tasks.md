# 오늘 날씨 서버 작업

[요구사항](requirements.md)과 [설계](design.md)를 따른다. 담당·일정·상태는 GitHub Project에서 관리하며 이 문서는 작업·검증 계획이다. 구현 작업은 [서버 Issue #11](https://github.com/kdywjs/weatherhood-server/issues/11)과 연결한다.

1. 인증키를 안전하게 설정하고 한 지역에서 오늘 00시 소급, 세 종류 기상 자료, 미세먼지 측정 구간·결측·게시 지연을 검증한다.
2. 전국 읍·면·동 대표 좌표·기상 격자·도시대기 측정소 연결을 검증한다. [지역 선택](../location-selection/server-tasks.md)의 지역 원본과 ID를 공유한다.
3. 인증 설계 의존성을 확인하고 API 계약·응답 예시·강수량 매핑을 작성한다.
4. 관측·자료 종류별 최신 예보 저장, 발표 시각 비교 갱신, 요청 기반 수집·중복 합치기·시간 예산·재시도 제한을 구현한다.
5. 오늘 시간별 응답·최신 미세먼지 요약·예보 최고/최저·일출/일몰 조합과 null·부분·전체 실패·이전 자료 허용 경계를 구현한다.
6. 최초 조회/DB 조회 성능과 공급처 호출량·행 수·저장량을 측정한다. 전국 지원·응답 성능을 증적 없이 완료 처리하지 않는다.

7. 한국천문연구원 출몰시각을 연동하고 대표 좌표·한국 날짜별 DB 재사용, 다음 날짜 수집과 부분 실패 보충을 구현한다.

## 검증 항목

- 일출·일몰의 당일 재조회 방지, 재시작 후 재사용, 날짜 변경, 부분 누락 재시도, 응답 날짜·시간 검증.
- 한국 날짜 경계, 24개 슬롯, 현재/과거/미래의 출처 및 집계 구간.
- 강수량 0·미만·범위 경계·변환 불가, 미세먼지 최신값의 미래 복사 방지.
- 동시 요청 중복 수집, 이전 발표의 지연 도착, 결측으로 정상 자료 덮어쓰기 방지.
- 새 발표 미게시, 공급처 오류·429·인증 오류, 2초 호출/5초 요청 제한, 재시도 대기.
- 최신 요약 2시간·초단기 6시간·단기 12시간 허용 경계와 지난 관측 보존.
- DB가 빈 상태의 오후 첫 요청과 일부/전체 공급 실패. 유효한 0도 부분 성공으로 처리.
- 같은 행정동 현재 위치/수동 선택의 동일 결과, 대표성이 부적절한 측정소 자동 대체 방지.

## 참고 및 검증

공급처 표본 인증 조회 결과는 [설계의 참고 및 검증](design.md#참고-및-검증)을 참조한다. 자동 테스트와 구현 실행 증적은 [서버 README](../../../weatherhood-server/README.md#참고-및-검증)를 참조한다. 전국 공급·부하 검증은 남아 있다.
