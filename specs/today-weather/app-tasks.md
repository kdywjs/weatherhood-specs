# 오늘 날씨 앱 작업

이번 기능은 서버 데이터 제공 명세이며 독립적인 화면 구현 작업은 없다. [요구사항](requirements.md)과 후속 API 계약을 화면 기능의 연동 작업에서 참조한다.

화면 명세는 24개 슬롯의 null, 최신 미세먼지 요약과 시간별 값의 차이, 일부 값이 없는 응답과 하루 공통 일출·일몰 시각을 고려한다. 표시 방식과 낮·밤 전환 활용은 화면 명세에서 정한다. 누락 원인과 이전 자료 사용 여부는 전달받지 않으며 서버가 유효성을 판단한다. 재생·캐릭터·배경·오류 문구는 [날씨 표현 명세](../weather-presentation/requirements.md) 등 각 화면 명세에서 정하며 이 문서에서 확정하지 않는다.

서버 계약 확정과 공급 검증이 연동 검증의 선행 조건이다. 전용 앱 Issue·PR은 아직 없으며 앱 연동을 수행한 것으로 간주하지 않는다.
