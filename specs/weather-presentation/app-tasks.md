# 날씨 표현 앱 작업

[요구사항](requirements.md)과 [설계](design.md)를 따른다.

1. 원본 강수 코드와 화면 표시 분류를 분리하고 누락·강수량 범위·집계 기간의 매핑을 검증한다.
2. SpriteKit 하늘·비·눈·혼합·풍속 효과, 개발자 설정, 초기화·크기 변경·비활성화·동작 줄이기를 검증한다.
3. 제외된 안개·연무·기온 색감·고정 시각 낮밤이 재도입되지 않는지 확인한다.
4. 기온별 의상 구간, 마스크 기준, 방수 소품 조합·우선순위와 앱용 자산을 합의한 뒤 캐릭터에 연결한다.
5. 현재 계약의 일출·일몰을 연결하고 경계 시각·한국 날짜·지역 변경·null을 검증한다. 박명은 계약 확장이 선행 조건이다.
6. 실제 API·실기기 성능·시각 조합을 검증한다. 개발자 샘플 성공을 운영 연동 완료로 처리하지 않는다.

일정·담당·진행 상태는 GitHub Project에서 관리하며 이 문서는 계획과 선행 조건만 정의한다. 앱 코드 전달 브랜치는 [feat/weather-presentation](https://github.com/kdywjs/weatherhood-app/tree/feat/weather-presentation)이며 병합 완료를 의미하지 않는다.
