# 날씨 기반 캐릭터·배경 표현 설계

원본: [요구사항](requirements.md). 데이터 계약: [오늘 날씨 API](../../contracts/today-weather-api.md).

## 앱 구조

- SwiftUI는 기온·문구·시간 눈금·주간 목록과 입력을 관리한다. 고정 배경 이미지 위의 투명 SpriteKit 레이어가 구름·빛·비·눈·혼합·풍속 효과를 표현한다. 텍스트나 주간 컴포넌트를 굴절시키지 않는다.
- 배경 이미지에 그려진 정지된 빗줄기와 입자를 겹치지 않는다. 비 장면에는 강수 없는 원화를 사용한다.
- 비는 먼 층·중간 층·전경으로 나누며 전경은 낙하 중 길이·크기·속도가 증가한다. 바닥 파문·튀김을 별도로 표현한다. 카메라는 고정한다.
- 눈은 별도 입자를 사용하고 혼합은 비와 눈을 함께 표시한다. 눈송이 밀도는 시안값이며 강수량 mm에서 유도하지 않는다.
- 구름 양·밝기는 하늘 상태로 구분한다. 움직임 방향은 실제 풍향이 아닌 연출이다.
- 습도 안개·대기질 연무·기온 색감·고정 시각 낮밤·사용자 지정 셰이더는 사용하지 않는다.
- 초기화 완료 후에만 입자를 배치하고 크기 변경·화면 복귀에서 입자 수가 급증하지 않도록 제한한다. 비활성화 때 정지하며 동작 줄이기에서는 애니메이션 레이어를 숨긴다.

## 입력 매핑과 개발자 도구

- 강수 형태 원본 → 표시 분류 → 입자 종류 순서로 처리한다. 원본 API 코드나 공급자 계약을 축약하지 않는다.
- 1시간 비 연출 구간은 3mm 미만 / 3 이상 15 미만 / 15 이상 30 미만 / 30 이상을 사용한다. 이는 비 표현 기준이며 특보나 위험 판단이 아니다. 범위 전체가 한 구간일 때만 해당 강도를 적용한다.
- 강수 형태는 비인데 강수량이 0·누락·다른 집계 기간이거나 범위가 구간을 걸치면 성긴 기본 비를 표시하며 실제 강도는 알 수 없는 상태로 취급한다.
- 현재 풍속 시안 구간은 2m/s 미만 / 2 이상 5 미만 / 5 이상 9 미만 / 9 이상이다. 기상청 강풍 특보 기준이나 최종 의상 정책이 아니다. 풍속 누락은 기본 낙하 방향을 사용하며 무풍으로 단정하지 않는다.
- Debug 개발자 모드에서 하늘·강수 분류, 시간, 수치·범위 강수량과 집계 기간, 풍속·기온·습도·강수확률, 최고·최저, 최신/시간별 PM10·PM2.5와 등급, 개별·전체 누락을 편집한다. 정보용 값과 효과용 값을 구분한다.
- 기본은 입력값 기반 효과다. 수동 강도 비교는 명시적으로 활성화하며 실제 날씨와 분리한다. 종료하면 원래 샘플 상태로 돌아간다. 최신·시간별 대기질 선택은 정보 표시용이며 배경을 바꾸지 않는다.

## 태양·캐릭터 연동

- 서버의 선택 날짜 일출·일몰을 받아 선택 시각과 비교한다. 고정 시간 임계값은 사용하지 않는다. 현재 계약의 두 필드로 낮·밤을 판정하고, 박명 경계는 계약 확장 이후에만 사용한다.
- 태양 시각은 매 프레임 조회하지 않는다. 조회한 날짜별 값을 재사용하며 다른 지역·날짜 값을 혼용하지 않는다.
- 기온은 기본 의상, 강수는 방수 소품, 대기질 등급은 마스크, 풍속은 움직임에 연결하는 구조로 분리한다. 실제 임계값·자산 조합·우선순위 확정은 선행 작업이다.
- 서버의 수집·보존·응답 책임은 오늘 날씨 스펙에 둔다. 이 기능은 서버가 임의 의상 코드나 새 박명 필드를 내려주도록 요구하지 않는다.

## 참고 및 검증

- 2026-11-15 로컬 앱은 가상 데이터와 SpriteKit 배경·Debug 설정을 구현했다. 습도 안개·대기질 연무·기온 색감·고정 시각 낮밤을 제거했다.
- 실제 서버 API, 자동 의상·우산·마스크, 일출·일몰 기반 낮밤은 앱 미연동이다. 캐릭터는 배경과 합쳐진 정지 이미지이며 정적 3D 의상 시안은 앱 완성 자산이 아니다.
- 최신 계약에는 sunriseAt·sunsetAt만 존재한다. 박명은 조건부 확장이고 계약 변경·공급 검증은 하지 않았다.
- 실행·검증 방법과 결과는 [앱 README](https://github.com/kdywjs/weatherhood-app/blob/feat/weather-presentation/README.md)를 참조한다. 실기기 성능·전체 조합의 시각 확인은 남아 있다.
