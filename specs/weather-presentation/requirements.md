# 날씨 기반 캐릭터·배경 표현 요구사항

## 목적과 범위

FO는 선택 지역·날짜·시각의 날씨를 캐릭터의 옷차림·소품과 배경으로 전달한다. 표현에 사용하는 기준은 기온, 강수 형태, 강수량, 풍속, 하늘 상태, PM10·PM2.5 등급, 태양 시각의 7가지다. 입력 계약은 [오늘 날씨 API](../../contracts/today-weather-api.md)를 따른다. API 원본을 유지하고 화면 표현용 분류만 앱에서 구성한다.

## 현재 표현 기준

| 입력 | 캐릭터·소품 | 배경 |
| --- | --- | --- |
| 기온 | 선택 시각에 맞는 반팔·긴팔·겉옷·패딩 등 기본 의상 | 기온에 따른 주황·파랑 색감 보정 없음 |
| 강수 형태 | 비·혼합 강수에 우산·우비 등 | 비·눈·혼합 강수, 강수 없음 |
| 강수량과 집계 기간 | 방수 소품 단계는 후속 결정 | 시간당 비의 밀도·바닥 튀김 |
| 풍속 | 옷자락·목도리 등 움직임 | 비·눈 기울기와 바람 움직임 |
| 하늘 상태 | 기본 의상 유지 | 맑음·구름 많음·흐림 |
| PM10·PM2.5 등급 | 마스크 착용 기준은 후속 결정 | 연무·황사·가시거리 추정 없음 |
| 태양 시각 | 기본 의상 유지 | 낮·밤, 박명 제공 시 새벽·해질녘 |

- 기온별 의상 구간, 마스크 착용 등급·해제 조건, 소품 우선순위와 충돌 해결은 미정이다. API가 의상이나 마스크를 직접 지정하는 것으로 취급하지 않는다.
- `rain`·`shower`·`drizzle`는 비, `snow`·`snow_flurries`는 눈, `rain_snow`·`drizzle_snow_flurries`는 혼합으로 표시한다. `none`과 null은 구분한다. 소나기·눈날림 전용 메뉴·효과는 제공하지 않는다.
- 강수 형태가 알려진 경우에만 해당 효과를 표시한다. 강수량·풍속만으로 비/눈, 소나기 또는 눈날림을 판정하지 않는다.
- 1시간 강수량일 때 비 강도를 연결한다. 다른 집계 기간을 나누거나 범위의 중간값을 만들어 강도를 추정하지 않는다. 강수량 mm를 적설량·눈송이 수로 변환하지 않는다.
- 풍향은 현재 계약에 없으므로 움직임 방향은 고정된 연출이다. 실제 풍향·구름 이동속도를 나타낸다고 설명하지 않는다.
- 최신 기온·대기질과 시간별 값을 구분한다. 시간 탐색 중에는 선택 시간의 자료를 사용하며 최신 대기질을 미래 슬롯에 복사하지 않는다.

## 태양 시각

- 현재 계약의 `daily.sunriseAt`·`sunsetAt`가 선택 지역·날짜에 대응하고 둘 다 유효할 때, 일출 이상·일몰 미만은 낮, 그 밖은 밤이다.
- 시민박명 시작/종료가 추후 계약에 포함되면 아침 시민박명 시작~일출은 새벽, 일몰~저녁 시민박명 종료는 해질녘으로 확장한다. 현재 계약에는 박명 필드가 없으며 이번 문서는 이를 추가하거나 서버 제공을 완료 처리하지 않는다.
- 일출·일몰만 있으면 낮·밤만 구분한다. 하나라도 없거나 날짜·순서가 유효하지 않으면 태양 상태는 미정이며 06~18시 같은 고정 시각으로 대체하지 않는다.
- 해질녘이 반드시 붉은 노을을, 밤이 반드시 달·별을 뜻하지 않는다. 밝기와 조명은 하늘 상태와 조합하며 자료 없는 현상을 만들어내지 않는다.

## 제외와 예외

- 습도로 안개·땀을, 대기질로 연무·황사를, 기온으로 배경 색감을 생성하지 않는다.
- 강수확률만으로 비를 내리거나 우산을 펼치지 않는다. 최고·최저는 선택 시간의 기온을 대체하지 않는다.
- 번개, 정확한 풍향, 적설량, 달·별·실제 노을은 현재 입력만으로 확정하지 않는다.
- 누락은 현상 없음이나 0으로 바꾸지 않는다. 해당 입력에 의존하는 효과를 중단하고 정보 없음으로 구분한다. 시간 슬롯 전체가 null이면 해당 시간의 효과를 만들지 않는다.
- 셰이더 굴절·화면에 맺힌 물방울 효과는 제외한다. iOS 동작 줄이기·앱 비활성화에 대응한다.

## 수용 기준

1. 7가지 입력의 역할을 분리하고 제외한 가안 효과가 실행되지 않는다.
2. 원본 강수 코드를 보존하며 화면은 없음·비·눈·혼합·정보 없음으로 묶인다.
3. 강수량 집계 기간·범위·누락과 풍속 누락을 구별한다.
4. 일출·일몰 경계와 한국 날짜를 검증하고, 박명 미제공 시 새벽·해질녘을 만들어내지 않는다.
5. 정적 캐릭터·가상 데이터·개발자 미리보기를 실제 API·자동 의상 연동 완료로 표현하지 않는다.

## 참고 및 검증

- 승인 근거: 2026-11-15 대화에서 6가지 날씨 기준 외의 가안 효과 제거, 태양 시각을 포함한 7가지 FO 표현 기준의 스펙 반영을 요청했다.
- 현재 구현 범위와 미연동 항목은 [설계](design.md)의 참고 및 검증에서 구분한다.
