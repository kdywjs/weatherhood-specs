# 날씨 표현 서버 작업

이번 표현 기준 정리에 직접적인 서버 코드·계약 변경은 없다. 데이터 제공은 [오늘 날씨 서버 작업](../today-weather/server-tasks.md)을 따른다.

- 기존 원본 강수 코드, 누락, 집계 기간, 일출·일몰을 유지한다. 앱의 표시 분류를 위해 공급 코드를 삭제하지 않는다.
- 시민박명을 통한 새벽·해질녘 확장은 공급 검증과 계약 합의가 선행되어야 한다. 현재 sunriseAt·sunsetAt만으로 박명 제공 완료를 표시하지 않는다.
- 자동 의상·마스크 선택을 서버 책임으로 임의 지정하지 않는다.
