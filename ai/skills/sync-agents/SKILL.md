# AGENTS.md 동기화

## 대상과 범위

- 원본: `weatherhood-specs/ai/AGENTS.md`
- 사본: 통합 작업 공간 루트의 `AGENTS.md`
- 경로는 통합 작업 공간을 기준으로 해석한다. 스펙 레포에서 시작했다면 상위 작업 공간을 확인한다.
- 이 스킬 실행 요청은 합의한 동기화 변경의 커밋·푸시까지 포함한다.

## 절차

1. 두 파일과 스펙 레포의 Git 상태를 확인한다. 파일이 없거나 작업 공간이 불명확하면 덮어쓰거나 새로 만들지 말고 사용자에게 확인한다.
2. 두 파일이 같으면 변경 없이 종료한다. 기존의 미커밋 변경을 대신 커밋하지 않는다.
3. 다르면 차이를 보여주고 `루트 → 스펙`, `스펙 → 루트`, 또는 양쪽 변경을 병합할지 확인한다. 사용자가 이미 방향을 지정했다면 다시 묻지 않는다. 수정 시각만으로 최신 파일을 판단하지 않는다.
4. 양쪽 변경이 겹치면 충돌 내용을 함께 정리한다. 합의되지 않은 변경을 버리지 않는다. 합의한 내용을 두 파일에 반영한다.
5. 두 파일의 내용이 같은지 확인하고 스펙 레포의 diff를 검토한다.
6. 루트 사본만 변경됐다면 커밋할 내용이 없으므로 종료한다. 스펙 원본이 변경됐다면 이번 동기화 변경만 스테이징한다. 기존 스테이징이나 같은 파일의 다른 변경을 분리하기 어렵다면 중단하고 상황을 알린다.
7. 적용 가능한 커밋 규칙이나 별도 커밋 스킬이 있으면 따른다. 동기화 변경을 커밋하고 현재 브랜치의 연결된 원격 브랜치에 푸시한다. 연결된 원격 브랜치가 없거나 이번 작업과 무관한 미푸시 커밋이 있으면 대상을 확인한다.
8. 동기화 방향, 변경 여부, 커밋과 푸시 결과를 알린다. 충돌이나 푸시 실패 시 변경을 보존하고 원인을 보고한다. 강제 푸시는 하지 않는다.
