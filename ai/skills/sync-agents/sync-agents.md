# AGENTS.md 동기화 스킬 안내

## 목적과 주요 동작

스펙 레포의 `ai/AGENTS.md`와 통합 작업 공간 루트의 `AGENTS.md`를 같은 내용으로 유지한다. 루트에서 개선한 내용을 스펙 원본으로 가져오거나, 스펙 원본의 변경을 루트 사본에 반영할 수 있다.

파일이 다르면 차이를 보여주고 반영 방향을 확인한다. 방향을 이미 지정한 요청은 추가 확인 없이 진행한다. 양쪽 변경이 겹치면 내용을 합의한 뒤 반영하고, 수정 시각만으로 덮어쓸 파일을 결정하지 않는다.

동기화 후 일치 여부를 검증한다. 스펙 원본이 변경되면 관련 변경만 커밋하고 현재 브랜치의 연결된 원격 브랜치에 푸시한다. 루트만 변경되거나 두 파일이 같으면 새 커밋을 만들지 않는다. 실제 절차와 예외 처리는 [SKILL.md](SKILL.md)에서 관리한다.

## 설치 방법

이 폴더는 팀이 공유하는 원본이다. 각자 사용하는 AI 도구에 맞는 스킬 경로에 폴더를 복사하거나, AI에게 이 폴더의 `SKILL.md`를 읽고 실행하도록 요청한다. 기존 설치본이 있으면 차이를 확인한 뒤 갱신한다. 자동 설치나 주기 실행은 포함하지 않는다.

동기화 대상은 설치된 스킬 폴더가 아니라 Weatherhood 통합 작업 공간의 두 `AGENTS.md`다. 다른 위치에서 실행할 때는 작업 공간 경로를 함께 전달한다. 커밋·푸시하려면 스펙 레포의 Git 원격과 인증이 설정되어 있어야 한다.

## 사용 예시

- “`weatherhood-specs/ai/skills/sync-agents/SKILL.md`를 따라 두 AGENTS.md를 비교하고 동기화해줘.”
- “루트 AGENTS.md의 변경을 스펙 원본에 반영하고 커밋·푸시까지 해줘.”
- “스펙 원본을 기준으로 루트 AGENTS.md를 동기화해줘.”

스킬 실행 요청에는 동기화 변경의 커밋·푸시가 포함된다. 관련 없는 변경은 포함하지 않으며, 실패하면 변경을 보존하고 상황을 알린다.
