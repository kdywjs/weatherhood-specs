# 이슈·PR 작성 스킬

이슈와 PR을 작성할 때 팀의 작업 관리 규칙과 대상 레포의 템플릿을 적용한다. 이슈 종류를 선택하고 핵심 정보를 작성하며, PR에는 연결된 이슈와 실제 변경·검증 결과를 기록한다. 생성한 이슈는 Weatherhood Project에 중복 없이 연결하고, 확인된 담당자와 요청한 필드 값을 반영해 등록 결과를 확인한다. 일정 유지 요청이 있으면 기존 날짜를 변경하지 않는다.

이 폴더는 팀 공유 원본이다. AI 도구의 스킬 경로에 설치하거나 [SKILL.md](SKILL.md)를 읽도록 요청한다. 현재 작업 공간에서는 `.agents/skills/write-issue-pr`에 원본 폴더를 연결해 사용할 수 있다.

예시:

- “테스트 설계 이슈를 스펙 레포에 작성해줘.”
- “현재 변경으로 PR 본문 초안을 작성해줘.”

초안 작성과 실제 게시를 구분한다. 실행 지침은 `SKILL.md`, 팀 규칙은 `rules/task-management.md`, 입력 양식은 각 레포의 `.github/`에서 관리한다.
